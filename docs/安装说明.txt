======================================================
  古墓丽影 9（Tomb Raider 2013 / Steam 版）
  简体中文
======================================================

【推荐方案：安装社区完整汉化包】
该汉化包重建了中文字库（Noto Sans SC），界面、HUD、字幕都不会出现方框。

需要先装好 .NET SDK 10 和 Git，然后在仓库根目录执行：

    powershell -ExecutionPolicy Bypass -File scripts\install-community-mod.ps1

脚本会自动找到 Steam 里的游戏、下载汉化包（约 1.1 GB）、解压、
构建 Mod Manager、安装并合并进 patch2.000.tiger。
游戏不在默认位置时加 -GamePath 参数：

    powershell -ExecutionPolicy Bypass -File scripts\install-community-mod.ps1 -GamePath "D:\Games\Tomb Raider"

装好后启动游戏，并在「语言」设置里选 Chinese / 中文。


【另一条路：纯文本繁转简（不推荐）】
    powershell -ExecutionPolicy Bypass -File scripts\build.ps1

它只把官方繁体文本（约 3388 条）转成简体并替换台湾用语，不动字体。
实测会在游戏内产生大量方框 —— 31.2% 的简体汉字在游戏的中文字库里没有字形，
因为那张位图字库只画了繁体字。仅在你想研究文本流水线时使用。


【卸载】
    dotnet tools\TrTextTool\bin\Release\net8.0\TrTextTool.dll uninstall "你的游戏目录"

或者：Steam 右键游戏 -> 属性 -> 已安装文件 -> 验证游戏文件完整性。


【注意】
  * 语音仍是英文，官方没有中文配音，只有文本与字幕是中文。
  * Steam 验证文件完整性或重装游戏后，补丁会被还原，重新运行安装脚本即可。
  * 本仓库不包含任何游戏资源文件，汉化包在安装时从作者官方 Release 下载。
